# TRPG 通用回合制战斗插件框架 (`st-combat-framework` v2.2)

一个专为 **SillyTavern（酒馆）** 与 **TauriTavern（纯前端无 Node.js 后端）** 打造的通用回合制 TRPG 战斗扩展。

## 核心特点（v2.2 高级与/或前提逻辑 + Buff 添加来源追踪）

- **🤖 AI 选目标模式（解决全员集火）**：每个角色/敌人可配置 `aiTargetMode`：**分散缠斗 (`target_first`，默认，先随机选目标再挑招，适合群怪)** / **全图集火 (`skill_first`，先选大招再全图找破甲目标，适合 Boss)** / **残血斩杀 (`lowest_hp`)**。
- **🔀 技能多组 与/或（AND / OR）复合前置条件**：
  - 技能支持配置任意个 **条件组**，可自由设置「组间 AND / OR」与「组内 AND / OR」，轻松组合任意复杂释放前提（如 `(目标有我挂的印记 且 不可有别人挂的束缚) 或 (自身狂暴 且 HP≤40%)`）；
  - 每条前提支持检查 `目标 / 自身 / 任意友方 / 任意敌方`，条件类型支持 `必须有状态 / 不可有状态 / 状态槽数值 / HP%`，且敌我 AI 选招会自动精准寻找满足全部前提的目标！
- **🏷️ Buff 添加来源追踪与按来源筛选**：
  - 所有技能/道具施加的状态自动记录施法者（HUD 悬停状态徽章可见来源），状态支持设置 **`自动记录施法者(同名刷新)`** / **`按施法者独立共存(不同人挂的同名Buff互不覆盖)`** / **`固定自定义来源标签`**；
  - 技能前提可直接按来源筛选：`任意来源 / 仅自己添加的 / 仅别人添加的 / 我方阵营添加的 / 敌方阵营添加的`（并支持 `_any` 任意状态与 `_any_restraint` 任意束缚状态）！

- **✍️ 创作模式（写卡助手全量读档）**：
  - 在设置页或 HUD 顶部点一下 **`✍️`** 即可开启创作模式（日常游玩关闭省 Token，HUD 折叠浮标会标出 `✍️创作` 防忘关）；
  - 开启后自动把当前全部职业树、状态槽、状态/Buff、技能（含完整公式/复合效果/倍率）、装备、道具、角色、敌人与触发规则的**完整精简 JSON** 注入给写卡助手，AI 再也不用盲猜已有设定；设置页另附 **「📋 复制当前配置」** 一键复制按钮。
- **✏️ 智能修改+新增导入模式（同时改旧 + 整条/整区替换 + 删除 + 新增）**：
  - 粘贴 JSON 导入升级为三模式：**「✏️ 修改+新增导入（推荐）」**、**「➕ 仅新增（不改已有）」**、**「🔄 完整覆盖导入」**；
  - 写卡助手只需输出一个 JSON 块，即可同时做到：**局部修改已有 ID 字段**、**`"_replace": true` 整条替换**、**`"_targetId" + "_renameTo"` 改名**、**`"_delete"` 删除旧项**、**`"_replaceSections"` 整块替换指定分区**，以及**新增全新条目**，导入后会清晰汇报每一类「改了几项 / 增了几项 / 删了几项」！

- **地下城/剧情动态战利品与产出指导体系（写卡助手双交付物）**：
  - 写卡助手世界书新增 **「地下城/区域装备与道具产出指导生成规范」**：只需告诉写卡助手你要写一个地下城/秘境/商店，它会自动产出「可直接增量导入的预设包」+「贴进游玩卡的分层掉落与防崩坏动态锻造指南」；
  - `<combat_event>` 全面升级支持 **8 类事件**（新增 **`loot_bundle` 宝箱批量战利品包**、`grant_status`、`level_up`，并支持事件附带新 `statuses`/`skills` 自动入库，HUD 多事件支持 **「✅ 一键全部收录」**，且自动反向同步 MVU Zod！）。
- **完整战斗闭环 & 战术深度**：
  - 新增 **`🏁 结束战斗`** 按钮（战后一键切回日常待机、自动撤回实时战况注入并写回 MVU `in_combat = false`）与 **`🛡️ 防御待机`**（0 MP 调息回蓝，彻底杜绝缺蓝/全冷却卡死）；
  - 技能新增 **命中率 (`hitRate`) / 暴击率 (`critRate`) / 暴击倍率 (`critMultiplier`)** 与 **前置状态槽门槛 (`requiredGaugeId / requiredGaugeMin`)**；
  - 状态/Buff 新增 **承伤倍率 (`damageTakenMultiplier`，如 `0.7` 减伤 / `1.3` 易伤)**；
  - 设置页新增 **技能关键词搜索**、全分类 **「📋 复制副本」** 按钮与智能 JSON 容错提取（粘贴带 AI 前后废话的 JSON 也能直接解析）。
- **多目标复合技能效果（`extraEffects`）**：
  - 单个技能除了主目标与主效果外，可自由添加任意条 **「🔀 附加复合效果」**，每条独立指定目标（`仅自身 / 同主目标 / 单体敌方 / 全体敌方 / 单体友方 / 全体友方`）、效果类型（`伤害 / 回血 / 回蓝 / 净化 / 仅改状态槽`）、独立公式（支持 `last_amount` 读取主效果刚打出的伤害/治疗量！）与状态槽增减；
  - 技能的 **「✨ 附加状态」** 同样扩展支持 `主目标 / 仅自身 / 全体友方 / 全体敌方` 四种施加对象！

- **无限自定义特殊状态槽（可自由增删 + 自定义范围，写卡助手直接配置）**：
  - 不再局限于 2 个固定状态槽！除默认 `gauge_a` / `gauge_b` 外，可在设置页一键 **「➕ 新增状态槽」** 或由写卡助手 JSON 直接增量导入任意数量额外状态槽（例如理智值 `0~100`、圣印/连击豆 `0~5`、腐化/魔素等）；
  - 全链路自动打通：角色初始值（`initialGauges`）、技能/道具增减（`selfGaugeChanges` / `targetGaugeChanges`）、Buff 每回合变化（`perTurnGauges`）、**Buff 状态槽增减额外倍率（`gaugeChangeMultipliers`，可按槽位与增/减方向设置倍率或完全阻挡，多 Buff 自动累乘）**、公式变量（直接写 `<槽位ID>` 与 `target_<槽位ID>`）、阈值触发与重置、HUD 进度条与 GM 微调、以及 MVU Zod 双向同步全部自动适配，且 100% 向下兼容旧版配置。

- **完整束缚/禁锢、挣扎与队友解救机制**：
  - 支持 **物理类束缚**（挣脱概率 = `血量% × (我方有效力量 / 敌方有效力量或物理道具强度)`）与 **法术类束缚**（挣脱概率 = `法力% × (我方有效精神 / 敌方有效精神或法术道具强度)`），全部自动计入 Buff/装备/加点后的实时属性；
  - 被束缚时普通技能自动锁定，HUD 自动浮现带实时概率预览的 **`⛓️ 挣扎脱离`** 按钮（也支持自定义 `effectType: "struggle"` 挣扎技）；
  - 支持两种解救方式：**施法者维持型**（任意队友攻击施法者立即解救）与 **禁锢道具型**（拥有独立血量，队友点 `🔨打碎` 即可攻击禁锢物解救且不伤队友）。

- **全折叠清爽配置界面**：侧边栏所有条目卡片与大段多选区（前置状态、附加状态、到期转化、装备常驻 Buff、技能勾选等）默认折叠并带已选计数摘要，每个列表顶部支持一键「↕ 展开/折叠」。
- **极致创作自由度（全面多状态 + 技能冷却 CD + 卖血/吸血公式 + 自身前置状态）**：
  - 技能支持同时附加**多个状态**（各自独立概率与目标/自身对象）、**冷却回合 CD**、**自身 HP 变化公式**（负数卖血献祭、正数吸血回复）、以及**自身与目标双前置状态**；
  - 状态/Buff 支持倒计时结束后**同时转化为多个新状态**；
  - 装备支持附带**多个常驻 Buff** 与解锁**多个专属技能**；道具与阈值规则同样支持**多状态**。
- **无经验值「修炼突破」成长 + 5 项自由加点 + 物法双抗体系**：
  - 独立区分 **物理攻击 (`atk`) / 物理防御 (`def`)** 与 **精神法攻 (`spi`) / 法术抗性 (`mdef`)**；
  - 角色通过剧情修炼（MVU Zod `level` 提升）或 HUD 点击「⬆️ 修炼升级」突破升级，自动发放自由属性点，支持在 HUD 前端直接加点（体质/力量/精神/物防/法抗）与洗点。
- **按世界观分类的职业树 + 三大技能池 + 内置「西幻」完整包**：
  - 技能按 **大组（世界观）+ 小组（职业池 / 通用技能池 / 怪物技能池）** 管理，职业进阶自动继承父职业技能并随等级解锁新技能；
  - 内置 `presets/western_fantasy_pack.json` 完整**西幻职业与技能包**（战士、牧师、法师[元素/亡灵]、游侠、圣骑士、祭司、野蛮人 + 通用技能池 + 怪物技能池 + 装备/道具/敌人图鉴），在设置页一键载入！
- **MVU Zod 轻量双向联动（单一数据源）**：只需在 MVU Zod 的 `stat_data` 中加入标准 `combat` 子区块（不影响时间/好感度/内心想法等其他变量，且不同步沉重的 Buff 列表），即可实现：
  - **MVU → 插件**：自动同步装备、技能、道具库存、日常剧情血量变化，以及 AI 写入的遇敌 `encounter_enemy_ids` / 增援 `reinforce_enemy_ids`（支持滑卡 Swipe 回滚）；
  - **插件 → MVU**：战斗中掉血、耗蓝、状态槽变化、换装备、喝药自动轻量写回 `stat_data.combat`，剧情 AI 无需重复记账！
- **AI 剧情感知与图鉴目录自动同步（3 个省 Token 独立开关）**：自动向剧情 AI 同步「我方当前装备/技能/背包」「战斗中敌我实时战况」以及「敌人/技能/装备/道具极简图鉴目录（ID+名称+简述）」；支持 AI 通过 `<combat_event>` 按 ID 精准**开战、战斗中塞增援敌人、发技能、发装备、发道具**（全部需玩家在 HUD 点击确认）。
- **技能前置状态条件**：支持为技能勾选多个前置状态，目标持有任意 1 个时自动解锁（HUD 实时锁定/亮起）。
- **自由组合 Buff 系统 + 到期自动转化**：取消单一模板限制，单个 Buff 可同时勾选「跳过行动回合」、配置每回合对 `HP / MP / 状态槽A / 状态槽B` 四种属性的同时增减、攻防倍率，并支持**倒计时结束后自动转化为另一个 Buff**（例如「过载爆发」结束转为「力竭」）。
- **特殊状态槽支持每回合自动增减**：状态槽A / 状态槽B 均可配置每回合自动增长或衰减，并可指定仅对「我方 / 敌方 / 双方全员」生效。
- **按角色卡自动隔离方案与战斗进度**：不同角色卡各自拥有独立的队伍/技能/装备/道具方案，切卡自动切换，战斗血量绝不串台。
- **1v1 ～ 6v6 完整回合制 + 装备栏 + 道具栏**：
  - **装备系统**：支持武器/头部/防具/饰品部位，穿戴自动增加属性（HP/MP/攻/防）、**解锁专属技能**，并支持**穿戴自动附带常驻 Buff**（卸下自动移除）！
  - **道具系统**：支持回复 HP/MP、公式伤害、**净化清除临时异常状态**、增减特殊槽和附加状态，可设是否消耗本回合行动。
  - **HUD 一体化操作**：默认折叠为可拖拽迷你浮标（适配窄屏防遮挡），展开后内置 `⚔️ 技能 / 🎒 道具 / 🛡️ 装备` 三页切换。
- **阈值触发增强（自动挂载 Buff + Prompt 自动注入）**：
  - 生命值、特殊计量条（0–100，满值或归零）或指定状态满足条件时，可**同时**自动给角色挂上指定 Buff/Debuff（支持“条件维持期间生效，解除即移除”或“刚达标触发一次并可选清零状态槽”）并通过 `setExtensionPrompt` 自动注入剧情引导词。
- **零代码可视化配置 + 粘贴 JSON 增量合并（配合写卡助手）**：
  - 所有配置均可在 Extensions 侧边栏表单编辑，还支持直接把写卡助手生成的 JSON 代码块粘进文本框一键**增量合并**，不覆盖原有内容。
- **安全战报输出 & AI 剧情联动（兼容 MVU Zod）**：
  - 战报仅支持 **填入聊天输入框（绝不自动发送）** 或 **复制到剪贴板**；
  - 配合内置的运行时世界书，可监听 AI 回复中的 `<combat_event>` 标签，在 HUD 弹出 **一键收录剧情装备/道具或一键开战** 确认条，不挑任何 MVU / MVU Zod 变量结构。

## 安装与更新方法（SillyTavern / TauriTavern）

1. 打开酒馆右上角 **扩展（Extensions）** 面板 → **安装扩展（Install extension）**。
2. 粘贴仓库地址：
   ```text
   https://github.com/baiming12/st-combat-framework.git
   ```
3. 后续更新只需在扩展列表里点击 **更新（Update）** 并刷新页面即可，你的自定义配置不会丢失。

## 配套世界书使用指南（`worldbooks/` 目录）

本仓库直接内置了两份酒馆标准世界书 JSON，进入酒馆 **世界书（World Info） → 导入（Import）** 即可直接导入使用：

1. **[`worldbooks/card_assistant_generator_lorebook.json`](worldbooks/card_assistant_generator_lorebook.json)**（挂在你的**写卡助手**角色卡上）
   - 告诉写卡助手本插件的完整 JSON 结构；
   - 你直接对写卡助手说：“帮我按这个世界观做 3 件带 Buff 的装备、4 个技能、2 种道具”，复制它生成的 JSON 代码块 → 粘贴进本插件设置页的 **「📋 粘贴 JSON 快速导入」** → 点 **「➕ 增量合并导入」** 即可 2 秒入库！
2. **[`worldbooks/combat_runtime_lorebook.json`](worldbooks/combat_runtime_lorebook.json)**（挂在**游玩角色卡**或设为全局世界书）
   - 规范 AI 遇敌时不擅自算血、严格按你发去的战报描写战斗，并兼容 **MVU Zod**；
   - 当剧情送你装备（如帽子）、药水或刷出敌人时，AI 在末尾附一行 `<combat_event>`，HUD 顶部会弹出绿色确认条让你一键收录/穿戴/开战。

## 技能与道具公式说明

内置安全无 `eval` 解析器，支持 `+ - * / ( )` 与以下变量/函数：

- **自身变量**：`atk`、`def`、`hp`、`max_hp`、`mp`、`max_mp`、`gauge_a`、`gauge_b`
- **目标变量**：`target_atk`、`target_def`、`target_hp`、`target_max_hp`、`target_gauge_a`、`target_gauge_b`
- **函数**：`max(a, b)`、`min(a, b)`、`floor(x)`、`ceil(x)`、`round(x)`、`abs(x)`、`rand(min, max)`

## 阈值提示词可用占位符

`{{unit_name}}`、`{{hp}}`、`{{max_hp}}`、`{{mp}}`、`{{max_mp}}`、`{{gauge_a}}`、`{{gauge_b}}`、`{{gauge_a_name}}`、`{{gauge_b_name}}`、`{{turn}}`
