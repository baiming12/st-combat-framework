# TRPG 通用回合制战斗插件框架 (`st-combat-framework`)

一个专为 **SillyTavern（酒馆）** 与 **TauriTavern（纯前端无 Node.js 后端）** 打造的通用回合制 TRPG 战斗扩展。

## 核心特点

- **纯前端零后端依赖**：无需 Node.js 服务、无需编译构建，直接通过 GitHub 仓库地址安装与更新。
- **零代码可视化配置**：所有角色（支持 **1v1 ～ 4v4**）、技能、Buff/Debuff、特殊计量条名称、阈值触发剧情提示词均可在酒馆 `Extensions（扩展）` 侧边栏直接表单编辑，实时保存，并支持 **一键导出 / 导入 JSON** 备份与记事本批量编辑。
- **防遮挡折叠 HUD**：默认折叠为可自由拖拽的角落迷你浮标，展开后自动适配窄屏与悬浮窗，绝不遮挡聊天输入框。
- **安全战报输出（绝不自动发送）**：释放技能或回合结束后，支持自动 **填入聊天输入框（不发送）** 或 **复制到剪贴板**，让你补充完自己的台词后再发给 AI。
- **阈值触发与 Prompt 自动注入**：当生命值、特殊计量条（0–100）或指定异常状态达到你设定的条件时，自动通过 `setExtensionPrompt` 向 AI 注入预设剧情引导词；条件解除后自动撤回。

## 安装方法（SillyTavern / TauriTavern）

1. 打开酒馆右上角 **扩展（Extensions）** 面板。
2. 点击 **安装扩展（Install extension）**。
3. 粘贴本仓库地址：
   ```text
   https://github.com/baiming12/st-combat-framework.git
   ```
4. 安装完成后刷新页面，即可在右上角看到迷你 **「⚔️ 战斗面板」** 浮标，并在 Extensions 侧边栏看到 **「⚔️ TRPG 通用回合制战斗框架」** 设置抽屉。

---

## 快速使用指南

1. **配置队伍与技能**：打开侧边栏的 **「参战角色(4v4)」**，勾选要出战的我方/敌方角色（最多各 4 人），修改名字、血量与可用技能。
2. **自定义特殊计量条**：在 **「基础与导入导出」** 中修改 `状态槽A`、`状态槽B` 的显示名称和颜色（例如改为怒气、理智、异常值等）。
3. **设置剧情触发提示词**：在 **「阈值提示词」** 中新建规则，写下满足条件时想让 AI 描写的剧情引导。
   - 支持占位符：`{{unit_name}}`、`{{hp}}`、`{{max_hp}}`、`{{gauge_a}}`、`{{gauge_b}}`、`{{gauge_a_name}}`、`{{gauge_b_name}}`、`{{turn}}`。
4. **开始战斗**：点击迷你浮标展开 HUD → 点击 **「开始战斗」** → 点我方卡片选行动者、点敌方卡片（或任意单位右上角 🎯）选目标 → 点击技能按钮！

## 技能公式支持说明

技能伤害/回复公式内置安全解析器，支持 `+ - * / ( )` 以及以下变量和函数：

- **自身变量**：`atk`、`def`、`hp`、`max_hp`、`mp`、`max_mp`、`gauge_a`、`gauge_b`
- **目标变量**：`target_atk`、`target_def`、`target_hp`、`target_max_hp`、`target_gauge_a`、`target_gauge_b`
- **常用函数**：`max(a, b)`、`min(a, b)`、`floor(x)`、`ceil(x)`、`round(x)`、`abs(x)`、`rand(min, max)`

示例：`max(1, atk * 1.5 - target_def * 0.4)`
